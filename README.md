# Marketing Campaign Performance Analysis

## Project Overview

This project analyzes marketing campaign performance data to evaluate
revenue, advertising spend, conversions, ROI, CTR, and conversion rates.

The project uses Python/Google Colab, SQL, Excel, and Power BI to analyze
marketing data and create an interactive dashboard.

## Objectives

- Analyze overall marketing campaign performance
- Compare revenue across different campaigns and brands
- Analyze marketing channels and their contribution to revenue
- Evaluate advertising spend and ROI
- Analyze conversions and conversion rates
- Compare performance across cities
- Analyze customer segments by age group and gender
- Create an interactive Power BI dashboard

## Tools & Technologies

- Pandas
- NumPy

- Microsoft Excel
